# 本地 Python AI 助手新手说明书

## 1. 安装与启动

安装 Python 3.10 或以上版本和 Ollama，在项目目录执行 `python -m pip install -r requirements.txt`。首次联网下载模型：

```powershell
ollama pull qwen2.5-coder:3b
ollama pull qwen2.5-coder:7b
ollama pull qwen2.5vl:3b
ollama pull qwen2.5:7b
```

双击 `start_local_python_ai.cmd`，等待出现“你>”。安装和模型下载完成后可断网使用。7B 占用更多内存，在 CPU 上生成大段代码可能较慢。

## 2. 文件保存位置

启动时的“项目目录”显示默认保存位置。新安装默认使用用户主目录下的 `OfflinePythonAI`。复制 `local-ai.config.example.json` 为 `local-ai.config.json` 可修改输出目录；已有本地配置会继续生效。指定“桌面”时保存到当前用户桌面，也可以直接指定其他磁盘的完整目录。

```text
请写一个 Python 计算器，并保存为 calculator.py
请写一个统计偶数个数的 Python 程序，把代码保存到桌面，文件名叫 answer.py
把刚才的代码保存到这个目录：D:\works\绘图项目，文件名叫 shield.py
```

新程序不指定文件名时保存为 `generated_program.py`，连续修改和另存沿用当前文件名。目录支持中文和空格。如果你只说“把代码保存到这个目录：”，助手会等下一条消息中的路径。只有保存要求时直接保存已有代码，不重新生成。

确认成功时会显示“已保存到：”和真实完整路径。覆盖前备份为 `.bak`，语法检查通过后才覆盖；检查失败会尝试修复一次。语法通过不代表逻辑正确，仍需测试实际功能。

例如先说“美国队长的经典圆盾是什么样的？”，再说“用 turtle 把刚才说的盾牌画出来”，然后说“把背景改成黑色”，最后说“把代码保存到这个目录：D:\works\绘图项目”。无需每次重复前文。

## 3. 3B、7B 与截图识题

```text
/model 3b
/model 7b
/model auto
/model
```

3B 通常较快，7B 用于更复杂的代码。这个开关控制写代码时的模型；常识和普通问答默认使用 Qwen2.5 7B 通用版 `qwen2.5:7b`，不会强行把日常问题变成编程题。通用版和原来的 Coder 编程版是不同模型。图形绘制默认选更可靠的 7B 编程版。模型不是百科数据库，仍可能答错。

模型安装完即可离线使用。CPU 生成长代码可能需要等待，助手会显示当前使用的模型。截图使用独立视觉模型：

```text
"C:\Users\YOUR_USER\Pictures\question.png" 帮我把这道题的代码保存到桌面
```

路径含空格时使用引号。助手先转写题目，再生成源码。图片应清晰，题目约束和样例应完整；需要人工核对识别结果。当前截图入口会生成文件，适合编程题。

## 4. 代码风格

通用偏好包括中文提示、简短中文注释、英文变量名、基础循环和条件判断。小题使用直接脚本，必要时才定义函数或类；题目输入输出格式优先。

在 `local-ai.config.json` 的 `style_reference` 中填写自己的参考目录。当前生成流程会读取其中 `5.py`、`15.py` 两个短示例；没有示例时只使用通用规则。也可以设置环境变量 `LOCAL_AI_STYLE_REFERENCE`，或在输出目录的 `local-ai-style-path.txt` 中写入参考目录路径。个人示例和本地配置不要提交到公共仓库。

```text
查看我的代码风格
关闭代码风格模仿
按我的代码风格写
```

开关只影响当前命令行窗口，重新启动默认启用。这是提示词参考，不是训练模型，生成风格不保证完全一致。

## 5. 修改、审查与运行

```text
/fix calculator.py 修复除零错误
/review calculator.py
/read calculator.py
/run calculator.py
/files
/help
/quit
```

这些命令中的相对路径位于输出目录。`/read` 将文件加入后续普通问答的参考上下文。`/run` 执行真实本地代码并显示输出、错误和退出码，不是隔离沙箱。需要键盘交互的程序建议在 VS Code 终端单独运行。

也可以直接说“加上中文注释”“把背景改成黑色”“修复刚才的错误”，助手会参考当前代码修改并保存。若已在 VS Code 手动改过当前文件，下次修改会先读取磁盘上的最新版本。只想询问时可以说“先解释，不要修改”。turtle、绘图窗口和摄像头程序建议在 VS Code 终端运行。

## 6. VS Code Continue

安装 Continue 和 Python 扩展，先备份用户目录下 `.continue/config.yaml`，再合并项目中的 `work/continue-config.yaml`。重新加载 VS Code 并保证 Ollama 正在运行。

在 Continue 中，日常问答可选“Qwen2.5（中文常识与对话 7B）”，编程可选快速 3B 或 7B；需要看图时选 Qwen2.5-VL 并附加图片。要修改文件，使用 Edit/Apply；单纯 Chat 不等于已保存。Continue 有自己的聊天历史，与桌面快捷方式打开的命令行会话不共享。上文的自然语言保存和自动路由属于桌面助手。

## 7. Word、PDF、PPT

将文件放在输出目录，用以下命令读取文字并追加回答到副本：

```text
/文档 题目.docx 完成里面的题目并给出答案
/文档 报告.pdf 总结重点
/文档 讲稿.pptx 给出讲解建议
```

结果带 `_AI完成` 后缀。当前不支持任意位置的精确原位编辑；扫描 PDF 需要另行 OCR。图片、复杂公式、长文档可能提取不全，PDF 中文字体和 PPT 长回答排版需要检查。

## 8. 机器学习和深度学习科研

先说明数据、任务、依赖和硬件限制，按“数据检查、基线、训练、评估、消融、复现记录”分步骤生成代码。固定随机种子，区分训练/验证/测试集，检查数据泄漏，保存配置和结果。

[科研提示词模板](../科研研究提示词模板.md) 可以直接使用。离线模型无法核实新论文；引用、实验结果和结论需要人工验证。训练依赖如 PyTorch、数据集和驱动需要另行安装准备。

## 9. 常见问题

**连接失败**：重新运行启动脚本；检查 Ollama 是否监听本机 11434 端口。

**启动报错**：保留错误窗口；`.cmd` 使用 Windows CRLF 换行，PowerShell 中文脚本使用 UTF-8 BOM。

**中文乱码**：在 VS Code 选择 UTF-8 编码；启动器已设置 Python UTF-8 环境。

**生成慢或不完整**：切换 `/model 3b` 或拆小任务。语法修复只能处理部分问题，不能代替功能测试。

**结束服务**：`/quit` 关闭助手；Ollama 可能仍在后台，可通过 Ollama 应用退出。不要关闭其他正在使用模型的任务所依赖的服务。

## 10. 本地与公开配置

公开仓库只包含源码、通用配置、说明书和示例，不包含模型权重、个人路径、参考作业或截图。本机 `local-ai.config.json`、风格路径文件、缓存和备份已加入忽略规则。运行时请求默认发送本机 Ollama；改用远程地址时，数据发送范围也会改变。

在仓库目录运行 `python work/create_manual_docx.py` 可在桌面生成本说明书的 Word 版本。

## 11. 上下文记忆与开始新对话

助手会把最近聊天、当前完整代码和保存目录放在项目内的 `.local-ai/conversation.json`，关闭后重新打开会自动恢复。该文件已被 Git 忽略，不应上传公开仓库。请一次只打开一个桌面助手窗口，避免两个窗口覆盖同一份记忆。

要换一个完全无关的话题，输入“开始新对话”，或输入 `/new`。这会清空会话记忆和临时保存目录，已经写到磁盘的代码文件仍保留。

记忆容量有限：磁盘最多保留最近 12 轮，模型每次按默认 8192 token 的预算读取最近完整轮次，当前源码单独保留。特别长的对话会忘记较早细节，超大代码会提示拆分任务。重要要求建议在新任务中重述；这次改进增加了上下文和通用模型，不是无限记忆或重新训练模型。

## 12. 让它记住要求和补充知识

可以直接输入“记住：这次所有图形背景用黑色，标题用中文。”助手会把它保留在当前会话笔记中，重启后仍会用于回答和代码生成。“开始新对话”会同时清空这些笔记；笔记容量为 1800 字符，适合简短的关键要求。

项目 `knowledge/common.json` 提供一小组可编辑的本地参考资料，目前覆盖经典美国队长圆盾、turtle 绘图、常用库和机器学习数据划分。助手会按问题和上文主题自动参考相关条目。你可以按已有 title、keywords、content 格式补充可靠资料，保存为同一目录下的 JSON 文件。

这能补充模型知识，但不等于完整百科或事实核查器。不在资料中的常识仍依赖模型，可能答错；科研事实、引用和实验结论必须核实。CPU 上生成代码可能需要一两分钟或更久。
